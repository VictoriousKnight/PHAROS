✓
Static-first security architecture

Uploaded documents are analyzed as data. Pharos does not execute macros, scripts, embedded executables, or document applications during analysis.

ANALYSIS PIPELINE

From suspicious document to safe output

Every scan passes through multiple defensive analysis stages before a final disposition is produced.

01

Ingestion

Validate the submitted file, identify its type, enforce resource limits, and establish a safe analysis boundary.

02

Extraction

Inspect document structure, relationships, macros, scripts, URLs, embedded objects, payload indicators, and behavioral capabilities.

03

Detection

Combine extracted security features with machine learning and rule-based analysis to estimate risk.

04

CDR

Remove or sanitize active and unsafe document content and reconstruct a safer document when policy permits.

CAPABILITIES

Built for document threat analysis

M

Macro Analysis

Detect VBA and XLM activity, execution capabilities, suspicious APIs, obfuscation, and macro-driven chains.

S

Script Analysis

Analyze PowerShell, JavaScript, VBScript, shell, and command-interpreter indicators without execution.

P

Payload Detection

Identify encoded, compressed, embedded, executable, staged, and in-memory payload indicators.

C

Content Disarm

Apply CDR policy to remove active content and reconstruct safer Office documents.

ML

Machine Learning

Produce a model-based risk probability using the project's trained feature schema and classifier.

R

Security Reports

Generate structured findings, decisions, integrity information, and analyst-friendly reports.
